# Behaviors

- Login: bounceInDown card, live clock, outlined primary button, loading text `登录中,请稍后。。。`
- Admin: click-driven sidebar, tags view, user dropdown, logout confirm, fullscreen
- Dashboard: dismissible Taobao notice, hover-fill metric cards, month scatter + year combo charts
- CRUD pages: search/clear, toolbar dialogs, row 查看/编辑, checkboxes
- Responsive: login stacks at ~768px (left panel hidden); admin sidebar collapses toward 60px
- No Lenis; native overflow on `.avue-main`
